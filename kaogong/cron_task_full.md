193	- **分数速算专项（西瓜 2026-10-06 要求扩充，必须有）**，六类轮着出：
194	  1. **分子分母同乘 / 同除**：约分、通分、把分母（或除数）凑成整十整百，如 0.125＝1/8；
195	  2. **分子分母同加 / 同减**：真分数同加变大、同减变小（假分数反过来）；「错位加减法」——分子分母同加（减）各自的若干倍，分数值不变；
196	  3. **化同法**：把两个分数的分子（或分母）化成相同，再比另一边；
197	  4. **差分法**：用两个分数的差分数与小分数比，同向得结论；
198	  5. **比大小**：交叉相乘、与 1/2 或 1 这类中间值比、取倒数比；
199	  6. **特征分数互换**：12.5%＝1/8、37.5%＝3/8、62.5%＝5/8、6.25%＝1/16、53.3%≈8/15 等，正反都要能用；

202	  1. **百化分（首选）**：r＝1/n → 增长量＝现期量÷(n＋1)（12.5%→÷9、10%→÷11、37.5%＝3/8→先÷11 再×3、25%→÷5）；
203	  2. **化除为乘**：r/(1+r)＝1−1/(1+r) → 增长量＝现期量−基期量；
204	  3. **修正法（假设分配/修正假设分配）**：用邻近的 1/n 先算，再按 r 的偏差往回收（29% 先按 30%＝3/13 得 27.7，再收 ≈0.7 → 27.0）；
205	  4. **假设基期法**：先假设一个整齐的基期量，乘 (1＋r) 与现期量对差，再把残差分配回去；
206	  5. **小/带小数的百分数走化分数**：6.5%＝13/200、8%＝2/25、15%＝3/20、24%＝6/25、6%＝3/50、9%≈9/109；
207	  另外必须配**反向题**：求基期量（现期量÷(1＋r)）、求增长率（现期÷基期−1）、以及**下降型**（分母用 1−r，求减少量）。
