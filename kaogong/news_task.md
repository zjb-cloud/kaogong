> ⚠️ **2026-09-28 西瓜改版：新闻网页「一天一期，不分早晚」**——当天这一期由**早上 06:30 的全套生成任务**负责（内容=总结前一天，`date` = 当天），本 06:30 简报任务**只负责聊天里的《每日世界简报》文字稿**，**不再写 `news-NNN.json`、不再发布网页**。
> 目标：给西瓜发一条 12~15 条的《每日世界简报》文字稿（社会民生/国家大事/世界运行为主，财经 ≤ 1/3）。

## 西瓜对简报的要求（原样保留）
① 不要全是财经股票，社会民生/国家大事/世界运行情况为主，【财经最多占三分之一】；
② 每件事分析四段：背后的逻辑 + 与全球历史同类事件对比 → 影响 + 如果要解决该怎么办；
③ 【格式】等宽纯文本表格式排版，有条有序；
④ 取消语音播报：只发文字内容，不要调 tts、不要发语音版；
⑤ 条数标准 12~15 条，内容要够量，宁多勿少。

【防截断】单条回复太长会被聊天窗口截断（约 4000 字上限）。如超过约 3500 字，分 2 条发出（第二条标「续前」），不得丢内容。

exec 运行 `cd C:\Users\Administrator\.openclaw\workspace; python news_digest.py`（脚本自动写 `workspace/digest_last.txt`），然后用 read 读 `C:\Users\Administrator\.openclaw\workspace\digest_last.txt`（不要用 PowerShell 重定向，会乱码）。

## 第 2 步 · 筛选 12~15 条
优先：领导人活动/出访/讲话、重大政策法规、国际冲突与外交、央行与利率、大选与政权变动、住房/医疗/社保/教育/就业/物价/食品安全、重大科技与科学发现、天气与灾害。
丢掉：地方会议、招聘、活动报名、个股日常公告、营销软文。

## 第 3 步 · 简报文字稿格式（严格遵守）
- 开头「今日一览」三栏等宽表（序号 ① / 主题 / 一句话），半角空格对齐，中文占 2 宽度。
- 每个栏目一行分隔线 `━ 一、国际 ━━━`；栏目分布：国际 3 / 国内政策与民生 3 / 社会与生活 2 / 科技与新知 2 / 跟你钱袋子有关的 2-3 / 涨知识一分钟 1。
- 每件事一个 4 行卡片，标签固定 2 字 + `｜` 分隔，内容前空 2 格：
```
① 日元贬至 157.53
    事实 ｜ …
    逻辑 ｜ （推演）…
    历史 ｜ …
    影响 ｜ …；对策：政策层面… / 普通人…
```
- 不要用 markdown 表格语法，不用框线字符，每行 ≤ 60 显示宽度，超长换行用 5 个半角空格缩进。
- 结尾「想深挖哪条说一声」。

## 第 4 步 · 防编造（重要）
事实只写素材里有的，没把握标「待确认」；历史参照必须是真实可查证的公认事件（1973 石油危机 / 2019 沙特阿美遇袭 / 1985 广场协议 / 1997 亚洲金融风暴 / 2008 金融危机 / 2010 欧债 / 2022 英国养老金危机…），没有合适先例就写「暂无可靠先例」，绝不硬扯；逻辑与对策标明「（推演）」；不做投资建议、不预测点位。

## 第 5 步 · 发简报（只发文字稿）
把第 3 步的文字稿作为本会话回复发出，到此结束。**严禁调用 tts、严禁语音版、严禁追加音频。**
简报末尾附一行：`📰 网页版精读+申论金句：https://zjb-cloud.github.io/kaogong/ → 📰 每日新闻`

## 第 6 步 · 台账
往 `memory\kaogong\news_log.md` 追加一行（日期 / 简报条数 / 主要栏目分布 / 主素材主题），供次日 07:25 新闻页选题参考（**同主题两周内不重复**）；同时写回执 `kaogong\data\newsbrief-{{DATE}}.sent`（内容 `{{DATE}} HH:MM brief done`）。

## 铁律
- 宁可少写一条，不许编造；不确定的一律标「待确认」。
- **本任务不写网页数据、不跑 publish**（网页新闻期由 07:25 全套生成任务负责）。
- 聊天简报 12~15 条 ≠ 网页版 2~3 条精读，两者互不替代。
